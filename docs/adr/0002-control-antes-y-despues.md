# 0002 · Control antes y después

Estado: Aceptada · 2026-11-07

## Decisión
La persona aprueba el plan antes de implementar y lee el informe al final. No supervisa en el medio.

## Alternativas descartadas
- Aprobar cada sub-task: el run deja de ser desatendido.
- Solo leer el informe: un plan equivocado sale caro de deshacer.

## Consecuencias
- El run espera sin proceso vivo en la aprobación.
