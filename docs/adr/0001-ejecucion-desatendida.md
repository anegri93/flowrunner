# 0001 · La ejecución es desatendida

Estado: Aceptada · 2026-11-07

## Contexto
En flowindex, el trabajo de los agentes de un run tardó del orden de una hora y el run tardó unas 16 horas hasta la PR: el resto fue espera de una persona.

## Decisión
Un run corre sin que la persona mire. Las preguntas se responden antes de lanzar; durante el run, una duda no crítica se decide y se registra con su motivo.

## Consecuencias
- La entrada tiene que llegar completa: la feature se escribe en conversación antes del run.
- Cada decisión tomada sin la persona queda en el informe.
