# 0008 · El cerebro vive en el repo

Estado: Aceptada · 2026-11-07

## Decisión
Convenciones, contexto, qué es bien, ejemplos y lecciones viven en .flowrunner/ dentro de cada repo, versionados y revisados por PR. Cada run usa la versión de su rama.

## Consecuencias
- Un repo sin .flowrunner/ no se puede lanzar.
